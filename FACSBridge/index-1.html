Human Evaluation & Verification Protocol (v5.0)

Structured multi-stage evaluation pipeline for subjective and objective FACS verification.

Part A — Blind Perception

Raters judge expression emotion & visible movements from image evidence alone, prior to viewing prompt targets.

Part B — Targeted AU Rating

Detailed assessment of each requested AU: visibility, FACS A-E intensity scale, target comparison, and left/right symmetry.

Part C — Prompt Match

Evaluates overall expression fidelity, micro-expression vs full pose distinction, and non-expression attribute preservation.

Part D — Realism & Quality

Ratings for facial realism, anatomical plausibility, participant identity preservation, and region-specific artifacts.

# FP8 LINEAR WEIGHT CASTING & READ-WRITE LOCKING
# ============================================================

def store_linear_weights_fp8(model):
    """
    Stores Linear weights in FP8 (float8_e4m3fn) and upcasts a temporary 
    copy per call. Thread-safe execution allows parallel jobs to share 
    a single resident copy in VRAM (~12 GB FP8 FLUX.1 Transformer).
    """
    for name, module in model.named_modules():
        if type(module) is not torch.nn.Linear or _FP8_SKIP.search(name):
            continue
        module.weight.data = module.weight.data.to(torch.float8_e4m3fn)
        module.forward = functools.partial(_fp8_linear_forward, module)

# ============================================================
# MULTI-GPU STAGE LOCKING & CONCURRENCY
# ============================================================

_N_GPUS = torch.cuda.device_count() if torch.cuda.is_available() else 0
GEN_GPU = int(os.getenv("GEN_GPU", "0"))
EDIT_GPU = int(os.getenv("EDIT_GPU", "1" if _N_GPUS > 1 else "0"))
DUAL_GPU = GEN_GPU != EDIT_GPU

def stage_lock(stage):
    if GEN_PARALLEL and stage == "qwen":
        return _QWEN_LOCK
    if GEN_PARALLEL and stage == "flux":
        return _NO_LOCK
    if EDIT_PARALLEL and stage == "vlm":
        return _VLM_LOCK
    if EDIT_PARALLEL and stage == "edit":
        return _NO_LOCK
    return _GPU_LOCKS[STAGE_GPU[stage]]
